SMART FOOD SAVER - PYTHON PROJECT FILES

Files:
  Smart_Food_Saver.csv   Original dataset converted from your uploaded table
  data_cleaning.py       Cleans the dataset and creates clean_dataset.csv
  Data_analysis.py       Produces analysis_report.txt and summary CSV files
  Data_visualisation.py  Creates five charts as PNG files
  requirements.txt       Required Python libraries

HOW TO RUN (VS Code terminal):
  1. Open this folder in VS Code.
  2. Install dependencies:
       python -m pip install -r requirements.txt
  3. Run cleaning:
       python data_cleaning.py
  4. Run analysis:
       python Data_analysis.py
  5. Run visualisation:
       python Data_visualisation.py

Run the scripts in this order. The output files are saved in the outputs
folder. The original dataset is not overwritten.
